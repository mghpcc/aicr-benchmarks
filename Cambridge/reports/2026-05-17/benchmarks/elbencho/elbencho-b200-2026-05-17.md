## Command Runbook

Commands are shown with the public Make interface. Each applied launch was preceded by a Slurm queue check and was run only when no Elbencho/storage job was active.

```bash
squeue -u $USER -o "%.18i %.9P %.32j %.8T %.10M %.10l %.6D %R"
```

1. Small-block thread and I/O-depth sweep on `b0002`.

```bash
for threads in 32 64 128; do
  for iodepth in 16 32; do
    ELBENCHO_TARGET_ROOT=/scratch/csim/elbencho \
    ELBENCHO_THREADS=${threads} ELBENCHO_IODEPTH=${iodepth} \
    ELBENCHO_CPUS_PER_TASK=128 ELBENCHO_REPEAT_COUNT=1 ELBENCHO_TIME=01:00:00 \
    AICR_ELBENCHO_B200_APPLY_ALLOW=1 \
    make benchmark-elbencho CLUSTER=b200 WORKLOAD=small-block PROFILE=small NODES=1 \
      NODELIST=b0002 FROM_NODE_REPORT=1 NODE_REPORT_DATE=2026-05-16 APPLY=1
  done
done
```
