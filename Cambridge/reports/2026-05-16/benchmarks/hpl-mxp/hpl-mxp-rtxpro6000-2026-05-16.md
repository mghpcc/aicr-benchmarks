## Matrix Ladder

Relative per-rank matrix footprint is the SOW matrix-size estimate per rank, normalized to the one-node baseline. It is computed as `(N^2) / (baseline_N^2 * node_count) * 100` using the SOW sizing convention. This matters because the HPL-MxP campaign is a weak-scaling ladder: each larger node count should carry a similar matrix footprint per GPU/rank so the rows compare system scaling rather than simply increasing or reducing per-rank problem size. It is not measured GPU memory utilization and it is not the FP16 storage footprint.

| Nodes | GPUs | N | NB | Grid | Relative per-rank matrix footprint % |
| ---: | ---: | ---: | ---: | --- | ---: |
| 1 | 8 | 380000 | 2048 | 4x2 | 100.00 |
| 2 | 16 | 530000 | 2048 | 4x4 | 97.26 |
| 4 | 32 | 750000 | 2048 | 4x8 | 97.39 |
