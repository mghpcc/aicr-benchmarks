# B200 Elbencho Storage Study

Purpose: summarize B200 Elbencho storage measurements for small-block,
small-file, metadata, and peak-cluster workloads.

## Overview

B200 measurements were collected for one-node `small-block`, `small-file`, and
`metadata` workloads, plus a 30-node `peak-cluster` workload on `b0002-b0031`.
The one-node rows include parameter sweeps and selected five-sample
confirmation repeats. The peak-cluster row includes five samples and remains
`Partial` against the 31-node SOW shape because `b0001` was not available for
this collection.

## Scope

- The one-node small-block, small-file, and metadata rows cover the Benchmark 0
  workload families for the measured B200 client placement.
- The 30-node peak-cluster row covers the available B200 node set and remains
  `Partial` against the 31-node SOW shape until `b0001` is available.
- Metadata rows are non-cache-neutral because no cache-drop helper was used.
- Elbencho records filesystem-observed benchmark behavior; GDS readiness is
  covered by the [GDS module](../../gds/).
