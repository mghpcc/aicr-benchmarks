# Elbencho

Purpose: navigate the Elbencho storage benchmark module.

Elbencho measures storage behavior with small-block, small-file, metadata, and peak-cluster workloads against an explicit target root.

Use the Make interface for dry-run-first Slurm submissions, the script
interface for lower-level automation, and Studies for collected result pages
and artifact links.
